For the COS method, we have three sources of error: 
\begin{itemize}
    \item The integration range truncation error, $\varepsilon_1$.
    \item The series truncation error on $[a,b]$, $\varepsilon_2$.
    \item The error related to approximating $\bar A_k(x)$ by $\bar F_k(x)$, $\varepsilon_3$ \todos{(poner ref a alguna ecuacion)}.
\end{itemize}
It is important to note that there is no error in the payoff coefficient $H_k$ for plain vanilla European options.\\

If the integration range $[a,b]$ is chosen sufficiently large, the overall error is dominated by $\varepsilon_2$ \todos{(TODO: argumentarlo)}. Also, $\varepsilon_2$ converges exponentially if $f_X(x) \in C^\infty[a,b]$ \todos{(TODO: justificarlo tamb)}. Otherwise, converges only algebraically.\\

To choose an optimal integration range we will use the expression \todos{(TODO: ref a Oorsterlee)}
\begin{equation}
    [a,b]=\left[ (x+\zeta_1)-L\sqrt{\zeta_2 +\sqrt{\zeta_4}},\ (x+\zeta_1)+L\sqrt{\zeta_2+\sqrt{\zeta_4}} \right],
\end{equation}
where $L\in[6,12]$ is a parameter that depends on the tolerance we want to have, and $\zeta_i$ are the cumulants, computed using the expression \eqref{eq:cumulants}.
